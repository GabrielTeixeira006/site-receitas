🌎 5 Continentes, 10 Sabores

Sobre o projeto

O 5 Continentes, 10 Sabores é um site desenvolvido como projeto acadêmico.

O projeto reúne cinco países, cada um representando um continente, com duas receitas típicas que apresentam um pouco da diversidade gastronômica de cada região.

Países participantes

* 🇧🇷 Brasil
* 🇯🇵 Japão
* 🇦🇺 Austrália
* 🇮🇹 Itália
* 🇲🇦 Marrocos

Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

Objetivo

Apresentar receitas típicas de diferentes culturas por meio de um site responsivo e interativo, aplicando os conhecimentos adquiridos durante o curso.
